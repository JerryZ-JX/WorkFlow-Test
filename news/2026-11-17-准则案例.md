# 会计准则案例（10例）

收集日期：2026-11-17。下表整理了10个知乎上的会计准则相关案例，并附相关监管原文链接。

|---|---|---|---|
| 明宇制药：可转换优先股与许可收入 | 优先股公允价值变动显著影响亏损，许可协议形成当年主要收入。 | 知乎报道：明宇制药2025年确认许可协议收入2.64亿元；可转换优先股作为以公允价值计量且变动计入损益的金融负债，2025年相关公允价值变动约9.28亿元。分析时需核查许可的履约义务、收入时点及优先股转换条款。文章涉及2026年7月递表；转股属于上市后的预期，尚非已发生事实。 | [知乎文章](https://zhuanlan.zhihu.com/p/2071011534348759268) |
| 太合音乐：可转换可赎回优先股列报 | 赎回条款使优先股负债分类与损益成为财报焦点。 | 知乎报道：太合音乐2025年末16.12亿元可转换可赎回优先股列为金融负债，资产负债率为110.92%。赎回安排及公允价值变动影响负债和利润。核算需结合合同中的赎回、转换义务以及适用的财务报告准则判断。文章涉及2026年6月22日递表。 | [知乎文章](https://zhuanlan.zhihu.com/p/2061218541303509187) |
| 废弃电器电子产品拆解补贴 | 政府款项若实质为拆解服务对价，应按收入准则处理。 | 回收处理企业因日常拆解服务取得政府款项。证监会指引5-1指出，相关补贴不具无偿性，企业应按收入准则合理估计可变对价，并在满足确认条件时确认收入；不能仅凭付款方是政府就列为政府补助。指引发布于2025年7月18日。 | [知乎转载](https://zhuanlan.zhihu.com/p/1930734499127341413)；[证监会指引5-1](https://www.csrc.gov.cn/csrc/c100038/c7572064/content.shtml) |
| 药品合作研发中的客户合同 | 合作安排中的可区分许可，可能单独构成收入准则下的客户合同。 | 医药研发企业向另一制药企业授予特定区域的知识产权许可并交付技术资料，收取固定和可变对价。证监会指引5-2指出，若许可可单独区分且属于企业日常产出，该部分构成客户合同，应按收入准则确认许可收入。 | [知乎转载](https://zhuanlan.zhihu.com/p/1930734499127341413)；[证监会指引5-2](https://www.csrc.gov.cn/csrc/c100038/c7572064/content.shtml) |
| 履约完毕后减让合同价款 | 降价原因决定采用合同变更、可变对价重估还是债务重组。 | 企业履约并确认应收款后与客户协商降价。证监会指引5-3指出，若减让与履约瑕疵、退货、市场价格变化或惯例有关，应结合合同按销售合同变更或可变对价重估处理；若因履约之外的原因调整且符合定义，则按债务重组处理。 | [知乎转载](https://zhuanlan.zhihu.com/p/1930734499127341413)；[证监会指引5-3](https://www.csrc.gov.cn/csrc/c100038/c7572064/content.shtml) |
| 知识产权许可延期收入 | 新签许可延期安排时，收入可能要等到延长期开始才确认。 | 原知识产权许可到期前，企业按市场公允价格与客户约定延长授权期限。证监会指引5-4指出，如延期构成一项新授权合同，客户在延长期开始时才可使用并获益，因此延期收入应在该时点确认，而非签署延期协议时。 | [知乎转载](https://zhuanlan.zhihu.com/p/1930734499127341413)；[证监会指引5-4](https://www.csrc.gov.cn/csrc/c100038/c7572064/content.shtml) |
| 信用保险与预期信用损失 | 债权组合保险不能直接减少单项债权的预期信用损失。 | 企业为债权组合投保，共享赔付上限或免赔额。证监会指引5-5指出，这类保险不属于单项债权合同条款的组成部分，计量单项债权预期信用损失时不得考虑其影响；基本确定可获理赔且金额可靠计量时，按或有事项准则确认资产。 | [知乎转载](https://zhuanlan.zhihu.com/p/1930734499127341413)；[证监会指引5-5](https://www.csrc.gov.cn/csrc/c100038/c7572064/content.shtml) |
| 业绩补偿直接支付给联营企业 | 投资方没有直接收款权时，不得确认业绩补偿金融资产。 | 联营企业控股股东将业绩补偿直接付给联营企业。证监会指引5-6指出，投资方无直接取得该款的合同权利，不能确认金融资产；联营企业在基本确定收款时将其作为资本性投入计入权益，投资方按权益法调整长期股权投资和权益。 | [知乎转载](https://zhuanlan.zhihu.com/p/1930734499127341413)；[证监会指引5-6](https://www.csrc.gov.cn/csrc/c100038/c7572064/content.shtml) |
| 处置子公司后的逆流交易抵销 | 丧失控制后，原已抵销的逆流交易未实现损益应在合并层面实现。 | 子公司向母公司销售资产产生的未实现损益曾在合并报表抵销。证监会指引5-7指出，处置或视同处置子公司并丧失控制时，投资方应在合并报表将相关损益计入当期处置子公司损益，并相应调整资产账面价值。 | [知乎转载](https://zhuanlan.zhihu.com/p/1930734499127341413)；[证监会指引5-7](https://www.csrc.gov.cn/csrc/c100038/c7572064/content.shtml) |
| 可转换债券的递延所得税 | 复合金融工具初始确认产生的特定暂时性差异，应确认递延所得税负债。 | 当可转债负债成分的计税基础等于票面金额并产生应纳税暂时性差异时，证监会指引5-8要求确认递延所得税负债，初始影响计入所有者权益；后续随负债折价摊销，递延所得税负债变动计入当期损益。 | [知乎转载](https://zhuanlan.zhihu.com/p/1930734499127341413)；[证监会指引5-8](https://www.csrc.gov.cn/csrc/c100038/c7572064/content.shtml) |
